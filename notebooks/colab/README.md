# Colab-specific stage notebooks

This directory is generated by `scripts/build_stage_notebooks.py`. It separates the two Python environments used by the experiment:

- The Colab notebook kernel runs diagnostics, pandas analysis, and matplotlib visualizations.
- `/content/mamba/envs/zip/bin/python` runs repository scripts that import vLLM, Transformers, and the pinned training stack.

Run `00_memory_and_config.ipynb` first. It clones or fast-forward pulls `https://github.com/wtree101/ZIP-RC-Colab.git` into `/content/ZIP-RC-Colab`, checks both environments, and writes the shared experiment configuration. The remaining notebooks use that fixed repository and interpreter automatically.

## Local edit to Colab execution

1. Edit or regenerate notebooks in the local repository.
2. Commit and push the changes to the `main` branch of `wtree101/ZIP-RC-Colab`.
3. Open a notebook through its **Open in Colab** badge, or select a Colab kernel from VS Code.
4. Run notebook 00 with `SYNC_REPO = True`; later notebooks use the checked-out remote repository.

The remote `/content` filesystem is ephemeral. Runtime data, models, metrics, and reports should be copied to Google Drive before disconnecting when they need to persist.
